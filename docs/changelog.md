# Changelog

### v0.1.0
- Добавлены эталонные контракты сервисов ИИ-моделей в `testdata/contracts/`: примеры запросов и ответов детектора, ASR и TTS, ошибок и результатов замеров EXP-2.
- Добавлен эталон ответа словаря детектора `testdata/contracts/objects-detector/vocabulary.response.json` с хешем словаря.
- Добавлена таблица случаев нормализации текста `testdata/contracts/asr-service/normalize.cases.json` - общее правило PLT-4 и ASR-4.
- Добавлен список фраз прогрева TTS `testdata/contracts/tts-service/prewarm_phrases.txt` - фразы правил опасности по умолчанию.
- Добавлены вектора протокола `alv.v1` в `testdata/protocol/vectors.json`: кадры, битые кадры, сообщения приложения и Шлюза, неверные сообщения.
- Добавлен скрипт `scripts/sync-contracts.sh`: копирует контракты в репозитории сервисов и приложения, с `--check` сверяет копии.
- Добавлена выдержка из общей спецификации в `docs/spec.md`.
- Добавлен скрипт `scripts/setup-dev-env.sh` подготовки машины разработки: Go 1.24.13, moq v0.5.3, JDK 17, Android SDK (API 37, build-tools 37.0.0), Gradle 9.8.2 и Python 3.12; лицензии Android SDK принимаются только с явным флагом.
- Добавлено описание подготовки машины разработки в `docs/development.md`.
- Добавлен каркас Шлюза на Go 1.24: модуль `github.com/nikarpoff/assistant-low-vision-platform`, точка входа `cmd/gateway` с остановкой по сигналу.
- Добавлен собственный printf-логгер `internal/logger` со строками `<LEVEL>: <message>` и уровнем из `APP_LOG_LEVEL`.
- Добавлены настройки Шлюза `internal/env`: все переменные окружения со значениями по умолчанию, проверки режима описания, модели, адреса поставщика и токенов при старте.
- Добавлены метрики Prometheus `internal/metrics` в собственном реестре: этапы, E2E, запросы, отказы сервисов и поставщика, активные сессии, отброшенные записи журнала.
- Добавлен HTTP-сервер с `GET /health` и валидатор запросов.
- Добавлена сборка distroless-образа `build/Dockerfile` и `.dockerignore`.
- Добавлены CI на GitHub Actions (генерация моков, gofmt, vet, тесты) и публикация образа в GHCR с тегами `latest`, `sha-<7>` и `v<semver>`.
- Добавлен скрипт `scripts/regenerate-mocks.sh`, моки исключены из git.
- README переписан на русском: назначение, стек, быстрый старт, таблица переменных, протокол, HTTP API, разработка, структура.
- Добавлен пакет `internal/protocol` протокола `alv.v1`: кодирование и разбор бинарных кадров PROTO-3 с лимитами снимка (`APP_MAX_IMAGE_BYTES`) и фрагмента аудио (64 КиБ), сообщения приложения и Шлюза PROTO-4 и PROTO-5 с проверкой обязательных полей и перечислений, проверка версии в `hello` (PROTO-10), коды ошибок PROTO-11 с `retryable`, длительности `timings` с одним знаком после запятой (PROTO-12). Кодек проходит все вектора `testdata/protocol/vectors.json`.
- Добавлена зависимость `github.com/google/uuid` v1.6.0 для `request_id` и `session_id`.
- Добавлены клиенты детектора, ASR и TTS `internal/upstream`: пул keep-alive соединений на каждый сервис, бинарные тела, заголовки `Authorization` и `X-Request-ID`, таймауты PLT-8, типизированные ошибки (`ErrBusy`, `ErrUnavailable`, `ErrTimeout`, `ErrUnauthorized`, `ErrRejected`, `ErrInvalidResponse`) и счётчик `alv_upstream_errors_total{upstream, reason}`.
- Добавлен потоковый клиент TTS: ответ отдаётся фрагментами из целых отсчётов, таймаут `APP_TTS_FIRST_CHUNK_TIMEOUT_MS` ограничивает ожидание первого фрагмента.
- Добавлен словарь детектора `internal/vocabulary`: загрузка при старте с нарастающей паузой между попытками, проверка классов, формы названий для количества и сопоставитель упоминаний `mentions`.
- Добавлен снимок конфигурации стенда `internal/snapshot` и `config_id`: `/v1/info` сервисов, поставщик и модель языковой модели (кроме режима `template`), собственные настройки Шлюза и метка варианта размещения `placement` на верхнем уровне, без секретов; обновление раз в `APP_CONFIG_REFRESH_S`.
- В README добавлены разделы о клиентах сервисов ИИ-моделей, словаре детектора и снимке конфигурации стенда.
- Добавлен клиент языковой модели `internal/llm` для любого OpenAI-совместимого поставщика: запрос с `stream: true`, параметрами генерации и `APP_LLM_EXTRA_BODY`, только заголовки `Authorization`, `Content-Type` и `Accept`, чтение SSE с комментариями и фрагментом `usage`, проверка поля `error` в каждом фрагменте, `model` и `system_fingerprint` из ответа, таймауты первого токена и всей генерации, виды отказа PLT-15 в метрике `alv_upstream_errors_total{upstream="llm"}`, без повторов и с проверкой TLS.
- Добавлена заглушка поставщика `cmd/fakellm` (`internal/fakellm`): поток SSE в формате Polza.ai, `/v1/models`, ключ, задержки и модель из флагов и переменных `FAKELLM_*`, все режимы отказа `FAKELLM_FAIL`, запись полученных запросов для тестов.
- README дополнен описанием клиента языковой модели, видов отказа поставщика и заглушки `cmd/fakellm`.
- Добавлен журнал запросов в PostgreSQL `internal/journal` (драйвер pgx v5): устройства, сессии с кодом участника `label`, запросы с полями поставщика языковой модели и `image_bytes`, этапы, метрики приложения, снимки конфигурации. Запись асинхронная, через буфер `APP_JOURNAL_BUFFER` и одного писателя пачками; при переполнении буфера или недоступной базе записи отбрасываются со счётчиком `alv_journal_dropped_total` и предупреждением в лог не чаще раза в 10 с. Пустой `APP_POSTGRES_DSN` выключает журнал.
- Добавлены миграции схемы журнала `migrations/` и их применение при старте с таблицей `schema_migrations`.
- Добавлена обёртка пула соединений `internal/postgres` под интерфейсом для моков.
- Добавлен пакет `internal/stats`: перцентили nearest-rank, доля откатов `FallbackShare` и статистика `/v1/stats` по этапам, E2E, `degraded_reason`, `llm_error` и `llm_model`. Форма ответа закреплена эталоном `testdata/stats/stats.response.json`.
- Добавлены обработчик `GET /v1/stats` и проверка админ-токена для `/v1/stats` и `/v1/config` (`401` без токена).
- Добавлены интеграционные тесты журнала с PostgreSQL в Docker и скрипт `scripts/test-integration.sh`.
- Добавлено развёртывание `deployments/`: файлы compose вариантов размещения A (`compose.single.yml`, `compose.vm-proxy.yml`) и B (`compose.vm.yml`, `compose.models.yml`), стенд на заглушках `compose.fake.yml` и сборка из соседних каталогов `compose.local-build.yml`; сеть `alv-net`, настройки только через `--env-file`, чужие образы закреплены версиями, порты - только 80 и 443 Caddy наружу, остальные на адресе туннеля или `127.0.0.1`.
- Добавлены `caddy/Caddyfile` (Let's Encrypt, TLS 1.2+, WebSocket без буферизации, таймаут чтения 120 с) и примеры конфигурации туннеля WireGuard для VM и машины моделей.
- Добавлен сервис gpt2giga 0.3.0 (профиль `gigachat`) с проверкой TLS по корневому сертификату НУЦ Минцифры `certs/russian_trusted_root_ca.pem`, выключенным журналом трафика и портом только на `127.0.0.1:8104`.
- Добавлены `.env.example` со всеми переменными обеих машин и `reference.env` эталонной конфигурации; модели эталонной конфигурации фиксирует задача 002.
- Добавлен скрипт `fetch-weights.sh`: план загрузки весов с `--dry-run` и загрузка в именованные тома через образы сервисов.
- Добавлен скрипт живой проверки поставщиков `llm-live-check.sh polza|gigachat` через `llmbench` из образа Шлюза.
- Добавлен README развёртывания: варианты A и B, туннель, TLS и порты, поставщики и сертификат НУЦ, веса, эталонная конфигурация, замер, живая проверка, неполадки.
- Добавлена нормализация текста `internal/textnorm` по PLT-4 и ASR-4; проходит все случаи `testdata/contracts/asr-service/normalize.cases.json`.
- Добавлено распознавание намерений `internal/intent`: фразы команд из `configs/intents.yaml` (или `APP_INTENTS_PATH`), «пожалуйста» в начале или в конце, остальной непустой текст - `question`, хеш файла для `config_id`.
- Добавлены правила опасности `internal/hazard` и файл `configs/hazard_rules.yaml` с правилами по умолчанию PLT-6: проверка классов по словарю детектора с именем правила в ошибке, уровни `danger` и `notice`, фразы предупреждений, совпадающие с контрактом прогрева TTS, cooldown по паре «класс, направление» с исключением `far` → `near`, хеш файла для `config_id`.
- Добавлена история устройства `internal/history`: последние сцены и реплики по `device_id`, лимиты `APP_HISTORY_SCENES` и `APP_HISTORY_TURNS`, очистка через `APP_HISTORY_TTL_S` после последней активности.
- Добавлена зависимость `gopkg.in/yaml.v3` v3.0.1 как прямая.
- README дополнен разделом о намерениях, правилах опасности и истории.
- Добавлены шаблоны промпта `prompts/default/` (`system.txt` с правилами DSC-3 и диалогом DSC-8, `user.tmpl`), встроенные в бинарник; `APP_PROMPT` выбирает имя или каталог на диске, хеш шаблона входит в `config_id`.
- Добавлено описание сцены `internal/describer`: порядок объектов DSC-2 и `focus=ahead`; шаблон DSC-4 (до двух опасностей, до пяти объектов группами по направлению, числа словами с формами словаря, ответы на «где X», «есть ли X», «X есть»), он же откат режимов `llm` и `vlm`; промпт DSC-5 с постоянной системной частью первой, объектами в компактном виде, фокусом, двумя предыдущими сценами, репликами и вопросом; режим `vlm` со снимком `image_url` (data URL), подсказками детектора и моделью `APP_VLM_MODEL`. Поставщику уходит только текст и в `vlm` снимок, без идентификаторов устройства и запроса.
- Клиент языковой модели передаёт `top_p` = 1 в каждом запросе (DSC-5); поле `top_p` запрещено в `APP_LLM_EXTRA_BODY` и добавлено в параметры генерации снимка конфигурации, поэтому `config_id` сменился.
- Добавлена WebSocket-сессия `/v1/session` (`internal/session`): подпротокол `alv.v1` без сжатия, токен устройства до upgrade, `welcome` с настройками приложения и `config_id`, ошибки `bad_request` и `payload_too_large` без закрытия соединения, закрытие с кодом 4001 при чужой версии протокола, отмена запроса по `cancel` и новым запросом с отбрасыванием всех его сообщений и кадров, ping каждые 15 с и закрытие без pong за 30 с, реестр сессий с `alv_sessions_active`, остановка по SIGTERM с ожиданием активных запросов до 5 с и кодом закрытия 1001.
- Добавлен конвейер описания по касанию (`internal/pipeline`): детектор, описание сцены, очистка текста DSC-7, поток предложений со склейкой коротких и лимитами в 3 предложения и `APP_MAX_ANSWER_CHARS` с закрытием потока языковой модели, не больше 2 синтезов TTS на запрос, аудио строго по порядку предложений, объекты с опасностями первыми и этапы PLT-14 в `timings` и `alv_stage_duration_seconds`.
- Добавлена сборка Шлюза из настроек `internal/app`; `cmd/gateway` запускает её, HTTP-сервер обслуживает `GET /v1/session`. Журнал пока не подключён к конвейеру.
- Добавлены заглушки детектора и TTS для тестов `internal/servicestub` и проверка накладных расходов Шлюза (`TestOverheadBudget`, не больше 15 мс p95).
- Добавлена зависимость `github.com/gorilla/websocket` v1.5.3.
